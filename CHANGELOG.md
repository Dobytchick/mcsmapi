# Changelog

## v1.1.0 — 2026-09-25

- Clarified installation, API usage, file transfer, and example documentation.
- Corrected command dispatch, file requests, URL handling, and response status checks.
- Stopped printing API keys in request URLs.

- Added `SendCommandResult` for the API's boolean command response and `UnzipTo` for a typed extraction destination. The original methods remain available for source compatibility.
